# Resume Analyzer

Runs fully in the browser. No API key, no server, no limits.

**Run:** open `index.html` in Chrome or Edge (internet is needed once to load the PDF and Word readers).
**Deploy free:** drag this folder into Netlify Drop, or run `vercel` inside it.

Upload a PDF, DOCX or TXT resume (or paste the text), then use the tabs:
Roles for you, ATS check, Section review, Interview questions (type any role, then click the button).
